# Scrimmage

Pressure-test red vs. blue on one clock.

Launch attacker moves and defender responses on a shared timeline, under fog of war: blue only acts on what its logging has detected, so quiet moves slip through. Investigate with malware analysis and forensics, then see whether you actually reached containment — or just isolated the first box.

**Good for:** Tabletops, training new analysts, and showing why isolating one host isn't containment.

**Live:** https://jon.glass/scrimmage/

A single self-contained page with no build step. Open `index.html` or serve the folder over HTTPS.
